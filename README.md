# User Service API

Part of the Ventrixe Event System – a microservice architecture for managing events.

## 📄 Overview

User Service is an ASP.NET Core Web API that handles user authentication and management.
This microservice is part of an MVP implementation of a larger event management system.

## ✨ Features

* Retrieve all users
* Retrieve a specific user by ID
* Register new users
* User authentication (login)
* Password hashing (simulated in MVP)

## 🛠 Technologies

* ASP.NET Core 8.0
* Entity Framework Core
* In-Memory Database (for MVP purposes)
* RESTful API Design
